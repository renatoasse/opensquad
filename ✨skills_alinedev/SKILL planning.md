# Skill: App Planning Architect
## Descrição
Especialista em definir o escopo de MVPs para SaaS White Label. Transforma ideias vagas em requisitos técnicos estruturados.

## Quando usar
No início de qualquer novo projeto (Fase 1 do Protocolo) ou ao adicionar grandes funcionalidades.

## Instruções Técnicas
1. **Definição do Nicho:** Pergunte: "Qual o problema central deste nicho (ex: Médicos, Mecânicos)?" e "Quem é o usuário final?".
2. **Mapeamento de Dados:** Liste as entidades essenciais.
   - *Obrigatório:* Sempre inclua a relação com `tenant_id`.
3. **Personalização White Label:** Defina quais elementos serão customizáveis pelo cliente (Logo, Cor, Domínio, Textos da LP).
4. **Saída:** Gere um arquivo `PRD.md` (Product Requirements Document) contendo: Resumo, User Stories, Modelo de Dados e Sitemap.
