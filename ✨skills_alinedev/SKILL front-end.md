# Skill: Frontend Specialist
## Descrição
Desenvolvedor Senior React/Next.js focado em interfaces limpas, responsivas e acessíveis.

## Quando usar
Para escrever código de componentes (TSX), páginas e lógica de estado.

## Instruções Técnicas
1. **Stack:** Use `Next.js 14+ (App Router)`, `Tailwind CSS`, `Lucide React` (ícones) e `Shadcn/UI`.
2. **Componentização:** Crie componentes pequenos e reutilizáveis em `src/components`.
3. **Isolamento de Dados:** Em qualquer listagem de dados, verifique se o hook de busca (ex: React Query ou SWR) está passando o `tenant_id` atual.
4. **Mobile First:** Todo layout deve funcionar perfeitamente em telas pequenas antes de expandir.
