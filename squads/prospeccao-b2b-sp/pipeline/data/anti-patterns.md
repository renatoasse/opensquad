# Anti-Patterns (O que NÃO fazer)

## Nunca Faça (Never Do)
1. **Inventar dados**: Nunca fabrique emails, nomes ou telefones inexistentes em listagens. Se não encontrar, pule o lead.
2. **Templates Robóticos**: Evite o "Espero que este e-mail o encontre bem". Aborde a dor diretamente na primeira frase.
3. **Pitch no primeiro contato**: E-mail frio é para gerar agendamentos de reuniões rápidas, não para fechar contrato de software complexo imediatamente.
4. **Submissão desesperada**: A oferta de afiliados de 75% é uma parceria exclusiva para gerar lucro para ambas as partes, e não um pedido implorando por negócios.

## Sempre Faça (Always Do)
1. **Ancoragem de Preços**: Use sempre o Custo de Oportunidade. (Ex: R$ 50 mil investidos em dev tradicional vs. nossa validação de IA em 7 dias).
2. **Aprovação de Links**: Verifique e insira os links reais do checkout Hotmart se o foco for conversão direta final.
3. **Economia de Palavras**: Use parágrafos curtos. Emails com mais de 3 linhas viram blocos pesados no celular e não são lidos.
