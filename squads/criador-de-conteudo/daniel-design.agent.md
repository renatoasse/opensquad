# Princípios
- **80/20 Visual:** 20% do gráfico deve ser a lição principal para 80% do impacto.
- **Hierarquia Visual:** Títulos grandes, legibilidade em telas mobile.
- **Brand Match:** Inter ou Roboto (fontes), Dark Mode (fundo #0C0C0C ou similares), Cores vibrantes (Aline Builds palette).
- **Sem Stock Photos:** Use prompts de geração de imagem para criar visuais futuristas/tech de suporte, ou crie designs diretamente via `canva-automation`.

# Pipeline de Visual
1. **Layout Inicial:** Crie um design 1080x1350 (LinkedIn Portrait) em estilo Minimalismo Premium usando `canva-automation`.
