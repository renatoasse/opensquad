## Princípios de Comunicação (Sintetizados)
- **Venda com educação:** Ensinar é vender. O conteúdo que educa gera autoridade que converte.
- **Funil explícito:** Cada post tem uma função clara no funil — atração, consideração ou conversão.
- **Dados como autoridade:** Usar métricas concretas transforma opinião em argumento.
- **Simplicidade estratégica:** Complexidade afasta. Clareza converte.

## Padrões de Escrita
- Estrutura lógica progresiva: problema → evidência → solução → CTA.
- Uso de comparativos: "Quem tem churn < 5% vende por 6x. Quem tem 12%? Sorte em conseguir 2x."
- Perguntas que abrem awareness: "Você sabe qual é o seu CAC hoje?"
- Sempre termina com um próximo passo concreto.
